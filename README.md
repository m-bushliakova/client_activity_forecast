# client_activity_forecast

Прогнозирование общей суммы транзакций клиента в следующем месяце для планирования маркетинговых активностей.

## Цель проекта

Прогнозировать общую сумму транзакций клиента банка в следующем месяце и использовать этот прогноз для планирования и оптимизации маркетинговых активностей банка.

## Бизнес-задача

Банк зарабатывает на комиссиях с каждой транзакции клиента (эквайринг, переводы, платежи). Чем больше транзакций - тем больше прибыль. Но маркетинговый бюджет ограничен, и отправлять предложения всем клиентам накладно и неэффективно.

Решение: Модель ранжирует клиентов внутри каждого сегмента и выбирает топ-20% - тех, кто с наибольшей вероятностью совершит много транзакций в следующем месяце. Им и направляются маркетинговые коммуникации (кешбэки, акции, персональные предложения), стимулирующие дополнительные транзакции.

## Общая логика решения

1. Сегментация клиентов

Клиенты делятся на 4 сегмента по сумме транзакций за прошлый месяц:

    S1 (0-100k) - малоактивные, потенциал активации

    S2 (100k-1M) - растущие, высокий потенциал

    S3 (1M-10M) - активные, основной источник выручки

    S4 (>10M) - VIP, непредсказуемое поведение

2. Ранжирование внутри сегмента

Для каждого сегмента строится отдельная модель, которая ранжирует клиентов по вероятной активности в следующем месяце. Используются признаки:

    Лаги сумм за прошлые периоды

    Тренды роста/падения

    Скользящие средние

    Сезонность

    Паттерны поведения

3. Выбор топ-20%

В каждом сегменте отбираются 20% клиентов с наивысшим прогнозом.

4. Маркетинговые коммуникации

Этим клиентам направляются персонализированные предложения:

    Кешбэк на популярные категории

    Скидки у партнеров

    Увеличенные кредитные лимиты

    Напоминания о платежах

5. Получение прибыли

Клиенты совершают дополнительные транзакции → банк получает комиссии → растет прибыль.

## Эволюция проекта
### Фаза 1. Выбор датасета

Первоначальный датасет с Kaggle оказался непригодным (всего 2.5 месяца данных, 75% клиентов с одной транзакцией). Выбран новый транзакционный датасет с глубиной 25 месяцев и 20 032 клиентами.

### Фаза 2. Feature Engineering

Создано 117 признаков по истории клиентов:

    Агрегаты сумм и количества транзакций

    Лаги (1,2,3,6,9,12 месяцев)

    Скользящие средние (3,6,12 месяцев)

    Кумулятивные статистики

    Признаки трендов и стабильности

    Сезонные компоненты

    Поведенческие паттерны (типы событий, счета)

### Фаза 3. Отбор признаков

Двухэтапный отбор для каждого сегмента:

    Корреляционный анализ - удаление сильно коррелирующих признаков (порог 0.95)

    Forward selection - добавление признаков, пока есть улучшение

Результат: сокращение признаков с 95 до 25-50 в зависимости от сегмента.

## Фаза 4. Оптимизация гиперпараметров

Для каждого сегмента с помощью Optuna подобраны оптимальные параметры LightGBM с временной кросс-валидацией.

### Фаза 5. Walk-forward валидация

Реалистичная оценка модели:

    Обучаем на train (16 месяцев)

    Предсказываем 1-й месяц val

    Добавляем этот месяц в обучение

    Предсказываем 2-й месяц val

    И так далее...

### Фаза 6. Финальное обучение

На работающих сегментах (S1, S2, S3) модель обучается на train+val и тестируется на отложенном тесте (4 месяца).

# **Результаты проекта**

### Ключевые бизнес-метрики

| Показатель | Значение |
|------------|----------|
| **Дополнительная выручка** | 48.6 млрд ₽ за 4 месяца |
| **Рост эффективности маркетинга** | +198% (в 3 раза лучше baseline) |
| **Достигнуто от идеала** | 88% |
| **Экономия бюджета** | 80% (тратим только на топ-20%) |

### Результаты по сегментам

| Сегмент | Клиенты | Lift | Выручка от топ-20% |
|---------|---------|------|-------------------|
| **S1** | Малоактивные (0-100k) | +538% | 162 млн ₽ |
| **S2** | Растущие (100k-1M) | +233% | 3.8 млрд ₽ |
| **S3** | Активные (1M-10M) | +192% | 69.4 млрд ₽ |
| **S4** | VIP (>10M) | -11% | (модель не работает) |

### Что это значит для бизнеса

- **Вместо** того чтобы тратить бюджет на всех клиентов или выбирать по сумме прошлого месяца, модель **выбирает топ-20% самых перспективных** клиентов в каждом сегменте
- **Результат**: при охвате только 20% клиентов получаем выручку **в 3 раза выше**, чем при наивном подходе
- **Дополнительно**: высвобождается 80% маркетингового бюджета для других активностей
